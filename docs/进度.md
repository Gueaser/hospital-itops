## 六、关键决策记录（面试会问"为什么"）

1. **为什么用 Spring Boot 4 而不是 3.x**：新建项目没有历史包袱，MyBatis-Plus 3.5.18 已支持 Boot 4（`mybatis-plus-spring-boot4-starter`），springdoc 3.x 也已适配。
2. **为什么接收请求用 DTO 而不是直接用 `Asset`**：`id` / `createdAt` / `updatedAt` 是数据库生成的，直接用 Entity 接请求会让别人能传 `"id": 1` 覆盖数据。
3. **为什么必须配 `PaginationInnerInterceptor`**：不配时 `selectPage` 是"假分页"——把全表查出来在内存里截取，数据量一大就崩。配了才是 SQL 层 `LIMIT`。
4. **为什么 `status` 要加 `SCRAPPED`**：需求边界写明"报废资产不能建单"，报废是资产的状态，不是工单的状态。
5. **为什么日期用 `LocalDate` / `LocalDateTime` 而不是 `java.util.Date`**：`Date` 可变、月份从 0 开始、时区处理混乱。
6. **为什么 `asset_code` 加 UNIQUE**：业务上资产编号是唯一标识，重复了就是脏数据。

## 七、踩过的坑（避免重复踩）

- **`@MapperScan` 漏了**：Mapper 接口找不到，启动报 `NoSuchBeanDefinitionException`。
- **MySQL 时区报错**：URL 里必须带 `serverTimezone=Asia/Shanghai`。
- **下划线转驼峰**：`application.yml` 里必须有 `map-underscore-to-camel-case: true`，否则返回的字段是 `asset_code`。
- **产出物必须放在仓库根目录内**：`docs/`、`sql/` 一度放在仓库外，`git add` 根本收不进去，commit 里是空的。
